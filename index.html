Diffusion-Based Model Fine-Tuning for Domain-Specific ArtUsing advanced diffusion models to generate art tailored to specific artistic styles, harnessing LoRA for efficient and memory-friendly fine-tuning. With Dr. Aurelia M. Davidson.

In this research project, I am focusing on adapting diffusion-based generative models to produce art that captures the unique characteristics of a specific artistic domain. By training on a curated dataset of art images, the model can learn style, color, and compositional patterns relevant to different art movements or media. The ultimate goal is to generate high-fidelity, style-consistent art while minimizing overfitting to the source domain.

Technical Details:

The foundation of this project leverages latent diffusion models (e.g., Stable Diffusion) as they enable high-quality image synthesis by operating in a compressed latent space. Specifically, a U-Net architecture with cross-attention layers processes latent representations, conditioned on textual or semantic prompts. For domain adaptation, I employ LoRA (Low-Rank Adaptation), which injects a small number of trainable parameters into the model's existing layers. This significantly reduces the GPU memory footprint and training time compared to full fine-tuning, making it ideal for iterative experimentation.

During training, the model receives text prompts describing the desired style or thematic elements of the art. Classifier-free guidance is utilized to balance creativity and fidelity, ensuring that generated art remains faithful to domain-specific styles (e.g., impressionism, surrealism, or modern digital art) without sacrificing originality. Data augmentation techniques, including random cropping, color jitter, and style-preserving transformations, enhance model robustness.

I also explore advanced sampling methods (e.g., DDIM or DPM++ solvers) to optimize inference quality and speed. Quantitative evaluation relies on metrics like FID (Fréchet Inception Distance) and KID (Kernel Inception Distance) to gauge image quality, while a separate user study measures subjective preferences for style accuracy. To accommodate large-scale experiments, I leverage PyTorch Distributed Data Parallel (DDP) on multi-GPU setups, maintaining version control for model checkpoints and hyperparameter configurations.

Technologies: Diffusion-Based Generative Models, LoRA, PyTorch, Hugging Face Transformers, DDP, Classifier-Free Guidance, Advanced Sampling Methods (DDIM, DPM++), Data Augmentation, Latent Spaces.

Keywords: Diffusion Models, Fine-Tuning, Domain Adaptation, Generative Art, LoRA, Latent Diffusion, Style Transfer, FID, Multi-GPU Training.

Audit Logging for Cyber-Physical Systems with Machine LearningMitigating adversarial effects in robot programming through audit logging and machine learning. The system safeguards against attacks, providing real-time feedback to ensure secure operations. With Dr. Sepehr Amir-Mohammadian.

In this project, I focused on mitigating adversarial effects in cyber-physical systems, particularly in robot programming. By integrating audit logging and machine learning techniques, the system ensures secure and reliable programming environments. My work involves using advanced algorithms to detect anomalies or adversarial behaviors that may compromise system integrity. Through robust audit logging mechanisms, this solution safeguards systems from attacks, providing real-time feedback to avoid disruptions during robot programming.

Technical Details: The machine learning models utilized in this project include a combination of spiking neural networks (SNNs) and Graph Neural Networks (GNNs) to accurately model the dependencies within the robot programming tasks. SNNs, which are inspired by biological neurons, offer real-time capabilities suited for event-driven tasks in cyber-physical systems. Adversarial training is applied using PGD (Projected Gradient Descent) to create adversarial examples during training, enhancing the model's resilience against real-world attacks. Additionally, the audit logging system integrates blockchain technology to ensure tamper-proof logs and secure storage, making it highly suitable for IoT-driven and real-time environments.

Technologies: Machine Learning, Audit Logging, Cybersecurity, Robot Programming, SNNs, GNNs, Blockchain.

Keywords: Adversarial ML, Cyber-Physical Systems, Secure Robot Programming, Spiking Neural Networks, Blockchain.

Release Notes Classification and Prioritization Using Deep LearningClassifying release notes based on key words and context, prioritizing these updates, and using advanced deep learning models to build a recommendation engine for user upgrades. With Dr. Solomon Berhe.

This project aims to revolutionize how software release notes are classified and prioritized. I developed a system to automatically categorize release notes based on keywords and contextual importance using state-of-the-art deep learning models. The system then ranks these updates in terms of priority and suggests important upgrades to users, ensuring critical updates are handled promptly. Additionally, the project includes a recommendation engine powered by advanced neural networks to further optimize the user experience.

Technical Details: The classification system is built on BERT (Bidirectional Encoder Representations from Transformers) for its ability to understand contextual semantics. Additionally, T5 (Text-to-Text Transfer Transformer) is used for sequence-to-sequence tasks, allowing for more nuanced categorization and summarization of release notes. For the recommendation engine, Neural Collaborative Filtering (NCF) with Variational Autoencoders (VAEs) is employed, enabling the system to personalize upgrade suggestions based on historical user behavior and priorities. The pipeline is optimized using Hugging Face's Transformers library and parallelized using PyTorch's DDP (Distributed Data Parallel) framework to scale on multi-GPU environments.

Technologies: Deep Learning, Natural Language Processing (NLP), Neural Networks, BERT, T5, VAEs, NCF, PyTorch DDP.

Keywords: Text Classification, Release Management, Deep Learning, Priority Ranking, Transformers, Neural Collaborative Filtering.

Virtual TA Using Retrieval-Augmented GenerationBuilding an intelligent assistant that can help students with course material using RAG and fine-tuned open-source LLM models for security. This assistant answers students' questions contextually based on professor lecture materials. With Dr. Vivek Pallipuram.

The Virtual TA is an intelligent assistant designed to help students with course-related queries. By integrating an open-source large language model (LLM) for security, I fine-tuned the model on lecture videos, notes, and other course materials from the professor. The system performs Retrieval-Augmented Generation (RAG) to answer student questions accurately and contextually. This project provides a secure, scalable solution to enhance student learning outside classroom hours.

Technical Details: The core of this system is a fine-tuned LLaMA 2 model, optimized for educational tasks using LoRA (Low-Rank Adaptation) for efficient and memory-friendly fine-tuning. The retrieval mechanism employs Faiss (Facebook AI Similarity Search) to efficiently handle large document corpora for semantic search. The RAG framework leverages both Dense Passage Retrieval (DPR) and Generative Transformers, allowing the model to pull accurate information from a knowledge base and generate coherent, context-specific answers. Security is ensured through differential privacy mechanisms and homomorphic encryption, safeguarding sensitive academic content while maintaining robust model performance.

Technologies: LLM, Retrieval-Augmented Generation (RAG), LLaMA 2, LoRA, Faiss, DPR, Transformers, Differential Privacy.

Keywords: Virtual Assistant, Educational Technology, Open-Source LLM, Fine-Tuning, Dense Passage Retrieval.

Exoplanet Discovery and AnalysisAnalyzing light dimming data from stars to discover and characterize exoplanets, calculating planet size, gravity, and other characteristics based on the light fluctuations and rotational speed of the stars. With Dr. Daniel Jontof-Hutter.

In this research project, I analyze exoplanetary data to understand the characteristics of planets orbiting distant stars. The analysis is based on light dimming patterns observed when a planet passes in front of its host star. By calculating the extent of dimming and the star's rotational speed, I estimate the exoplanet's size, gravity, and other characteristics. This project contributes to the scientific understanding of exoplanets and their potential habitability.

Technical Details: This project uses convolutional neural networks (CNNs) in combination with recurrent neural networks (RNNs) to process time-series photometric data collected from space telescopes like Kepler and TESS. The model architecture includes a hybrid CNN-RNN design, where CNNs handle spatial dependencies while LSTMs (Long Short-Term Memory networks) capture temporal patterns in the light curves. Bayesian optimization is employed to fine-tune model hyperparameters, ensuring high accuracy in detecting minute fluctuations in starlight. The project also incorporates Gaussian Processes for uncertainty quantification in exoplanet detection, providing probabilistic estimates of planet size and orbital characteristics.

Technologies: CNN, RNN, LSTMs, Bayesian Optimization, Gaussian Processes, Kepler, TESS.

Keywords: Exoplanets, Astronomy, Planetary Analysis, CNNs, RNNs, Bayesian Optimization, Gaussian Processes.

Open source

Since June 2026 I've had 272 pull requests merged into 22 repositories. Most fix the same shape of bug: nothing raises, a number is just wrong.

Three of those bugs

  1. got53must be9

    Gradient clipping ignored norm_type

    DeepSpeed's clip_grad_norm_ squared every per-tensor norm, so only the default p=2 came out right. On gradients [3, -4] and [2] with p=1 it returned 53. DeepSpeed itself passes p=2, so direct callers were exposed, for 933 days.

    DeepSpeed pull request 8313

  2. got0.000must be4.773

    Large gradients came out as zeros

    DeepSpeed's Muon path cast to fp16 before normalizing, so a large but finite gradient overflowed and the whole matrix collapsed. With gradients scaled 10,000x, the output was all zeros.

    DeepSpeed pull request 8533

  3. gotNaNmust be0

    A batch of one poisoned the loss

    In sentence-transformers' GOR loss, a single-input batch divided zero by zero. That happens whenever an epoch ends on a leftover sample, and the logged loss then stayed NaN for the rest of the run.

    sentence-transformers pull request 3921
